# LUCA IEX V0.2 · 독립 데이터 품질 연구판

**상태: 코드 작성 완료 / 실제 미국 시장 시험 미실시 / NOT_VALIDATED**

이 연구판은 기존 V0.1, 별도의 V0.2·V0.3, 운영 사이트, 예약 작업과 분리되어 있습니다.
GitHub 브랜치: `research/iex-quality-v02`. **main에는 반영하지 않습니다.**

## 쉬운 설명

- **IEX**: 미국 전체 거래소가 아닌 일부 거래만 보이는 창입니다. 0건은 전체 시장 거래가 없다는 뜻이 아닙니다.
- **완성된 1분봉**: 해당 1분이 끝난 뒤에야 확인할 수 있는 가격·거래량 기록입니다.
- **중복·수정 기록**: 같은 1분의 자료가 다시 오면 따로 기록합니다. 뒤늦은 수정 내용을 과거에 미리 알았던 것처럼 쓰지 않습니다.
- **빈 시간**: 분봉이 없는 1분이 끼어 있으면 연속적인 가격 움직임으로 취급하지 않습니다.
- **연구 패턴**: 거래량 증가·저점 상승·가격 변화를 동시에 관찰한 미검증 가설입니다. 매수 추천이나 급등 확률이 아닙니다.

## 실제로 만든 파일

- `quality.py`: 완성 분봉 검증, 시간 누락, 중복·수정 구분, 과거 시점 기준 분석
- `capture.py`: Alpaca IEX WebSocket으로 원본 거래/분봉을 수집하는 **수동 실행용 코드**
- `test_quality.py`: 가짜 데이터로 검사하는 오프라인 자동시험
- `outcomes.py`: 신호 이후 5·15·30·60분 IEX 체결 가격의 관찰 결과 계산 (매수 체결가 아님)
- `test_outcomes.py`: 미래 데이터 누출, 관찰 종료 전후, 자료 부족 자동시험
- `.github/workflows/luca-iex-quality-v02-live.yml`: 수동 전용 실제 IEX 관찰 워크플로 (9분/70분 선택, 연구 브랜치 한정)
- `.github/workflows/luca-iex-quality-v02-ci.yml`: 연구 브랜치의 코드 변경 시 **오프라인 시험만** 실행. API 키·주문·배포 없음

## 원본 기록 (실제 실행 시)

- `raw_events.jsonl`: 수신한 거래와 분봉의 필수 항목, 실제 수신 시각 포함
- `signals.jsonl`: 연구 패턴을 **처음 관측한 시각**. 검증 전이며 매수 신호 아님
- `summary.json`, `summary.md`: 종목별 품질과 자료 부족 표시

원본에는 API 키를 기록하지 않습니다. 원본은 IEX 범위에서만 유효합니다.

- 신호 발생 후 5·15·30·60분 **실제 시장 데이터** 결과 검증 (오프라인 계산 기능만 준비됨)
- SEC 희석, Float, 호가, 공매도, 실거래 가능성 검사

**주의:** 연구 브랜치에만 존재하는 새 워크플로는 GitHub에서 수동 실행 버튼이 보이지 않을 수 있습니다.
실시간 시험용 실행 경로는 기존 운영판을 건드리지 않는 방법을 별도로 검토해야 합니다.

## 5·15·30·60분 결과 판정 주의사항

- 신호 당시 확인된 완성 1분봉 종가를 **비교 기준**으로 씁니다. 실제 매수 가능한 체결가는 아닙니다.
- 신호 발생 후 5/15/30/60분 시점부터 60초 동안 실제 관측된 **첫 IEX 체결**과 비교합니다.
- 해당 구간까지 관찰하지 않았다면 `CAPTURE_ENDED_BEFORE_TARGET`로 표시합니다. 상승 실패로 기록하지 않습니다.
- 해당 구간에 IEX 체결이 없으면 `NO_IEX_TRADE_IN_WINDOW`로 표시합니다. 미국 전체 거래가 없었다는 뜻이 아닙니다.
- 원본 기록 상한에 걸리면 `INCOMPLETE_CAPTURE`로 표시하고 결과를 확정하지 않습니다.
- 70분 관찰을 해도 신호가 늦게 발생하면 60분 결과는 자료 부족일 수 있습니다.
- 현재 결과는 **수익률 예측 검증이 아니라 관찰 가능성 확인** 단계입니다.
