# 루카 V0.3 모바일 보고서 — 자료 연결 규칙 (2026-10-29)

## 실제 확인한 원본 구조
- `iex_raw_ohlcv_evidence.json`: `schema=LUCA_V03_IEX_RAW_OHLCV_EVIDENCE_V1`, `rows[].symbol`, `rows[].ohlcv[]` (t/o/h/l/c/v), `rows[].signals[].signal.signal_bar_start_utc`.
- `korean_forward_report.py`: 검증된 GitHub 실행의 `frozen_t0.json` 및 `forward_review.json`에서 한국어 Markdown을 생성.
- `research_auto_report.py`: **과거 SIP 재생용**이며 실시간 IEX와 섞으면 안 됨.

## 5·15·30·60분 변화율 계산의 안전 조건
1. 신호 발생 당시 종가 `c`가 실제 존재해야 합니다. 없으면 `확인 불가`.
2. 각 시점의 1분봉이 실제 기록돼 있어야 합니다. 없으면 `확인 불가`; **0%로 대체 금지**.
3. 신호 봉 시작 시각을 기준으로 N분 뒤 봉을 비교할 때, 반드시 기준을 문서에 명시하고 일관되게 적용해야 합니다. 권장: 신호 봉 종가 대비 N분 뒤 봉 종가.
4. 실제 기록에 없는 60분 뒤 결과를 임의 계산하지 않습니다. 현재 원본 수집의 `MAX_MINUTES=35` 제한 때문에 60분 결과는 대부분 또는 전부 확인 불가일 수 있습니다.
5. 신호 이후에 실제로 확인한 가격 변화일 뿐, 매수 체결 수익이나 예측 정확도가 아닙니다.
6. 신호가 여러 개인 종목은 각 신호를 구분하고, 하나만 골라 사후적으로 유리하게 보이게 하지 않습니다.
7. IEX 단일 거래소 자료이므로 미국 전체 시장을 대표하지 않습니다.

## 현재 구현 현황
- `mobile_report_viewer.html`: 로컬 한국어 MD/TXT 보고서 파일을 안전하게 텍스트로 표시하는 초안. 아이폰 실기기 검증 전.
- 기존 3차 실측 승인 장치, 실측 요청 파일, Secret, 시세 API 호출 및 실제 주문은 변경하지 않았음.
- 실제 5·15·30·60분 변화율 자동 계산·표시는 **아직 미구현**. 위 원칙을 만족하는 테스트를 먼저 작성할 것.

## 완료 기준
- 실제 저장된 원본 자료에서 누락 분봉/중복 시각/미래 정보/여러 신호를 다루는 검증 테스트 통과.
- 데이터가 없는 기간은 확인 불가.
- 모바일 화면의 수치와 재계산 결과가 일치.
- 실제 실측 없이는 성능 검증 완료를 주장하지 않음.
