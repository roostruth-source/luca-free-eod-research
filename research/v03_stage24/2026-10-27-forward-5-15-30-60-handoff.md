# LUCA V0.3 — 신호 이후 IEX 5/15/30/60분 검증 기능 (2026-10-27)

## 구현
- `research/v03_stage24/forward_outcomes_iex.py` : 미래 방향 T0 후보 동결 자료와 16분 관찰 보고서를 **검증한 이후**, 이미 끝난 IEX 1분봉을 GET으로 가져와 신호 이후 5/15/30/60분의 **가정상 IEX 가격변화**를 계산.
- 신호를 알 수 있던 순간의 **다음 1분봉 시가**를 가정 진입가로 두고, 각 경과 시간의 마지막 **IEX 1분봉 종가**를 비교. 실제 주문 가능성, 호가, 스프레드, 슬리피지, 거래정지, 수수료는 반영되지 않았으므로 **실현수익 또는 백테스트 승률로 표시 금지**.
- 1분봉 미수집/불연속 시 해당 시간 결과 **MISSING_IEX_MINUTES**. 누락 보간 금지.
- **신호 발생 뒤 60분 + 2분 추가 여유** 이후에만 자료를 조회. 미래 자료 유출 차단.
- T0 동결 해시, 기존 prospect review의 종목 순서, IEX 단일 거래소 표시, 발견 시각, 신호 기록 시각, 연구 등급 D/매수 차단 검증.
- 연구 후속 자료에서 A/B 매수 가능 등급 승격 불가능; SEC 접근 403 및 시총/Float 확인 미완료는 계속 UNKNOWN.
- **실제 전향 16분 관찰 아티팩트가 아직 없으므로 위 계산을 새로운 실제 신호에 적용한 결과는 0건**. 샘플 데이터를 사용한 오프라인 자동시험만 완료.

## 실측 품질검증
- GitHub Actions: https://github.com/roostruth-source/luca-free-eod-research/actions/runs/40482327124
- 전체 별도 연구판 회귀시험 **128/128 통과**. 신규 시험은 미래 시각 입력 거부, 유효한 60분 창 검증, 1분봉 누락, 동결 후보 바꿔치기, 승격된 매수 등급, IEX feed-only, 주문 API 부재 등을 포함.
- Workflow `.github/workflows/luca-v03-forward-outcomes-ci.yml`는 **오프라인 시험만** 실행, 예약·배포·사이트 갱신·거래 주문 기능 없음.

## 정확한 인수인계 (Work 담당)
1. 이미 준비된 연구 브랜치의 **단 한 번짜리** 전향 16분 실측 `luca-v03-prospective-live-once.yml`은 별도 요청 파일 `prospective_live_request.txt`를 미국 정규장 연구 시간에 생성/업데이트해야 실제 동작. 현재까지 **실제 실측 호출 미실행**. 과거 후향 관찰 8종목을 성과 자료로 재사용하지 말 것.
2. 실측이 완료되면 GitHub artifact의 `frozen_t0.json`과 `forward_review.json`을 **동일 Run에서** 확보.
3. 실제 첫 신호 이후 60분+여유가 지난 다음, Work가 연구 환경에서 두 파일을 `LUCA_FOLLOWUP_INPUT`로 지정해 `forward_outcomes_iex.py`를 실행하거나, GitHub 연구 브랜치 전용 후속 아티팩트 연결을 추가. 본 단계는 아직 **자동 아티팩트 회수/예약까지 구현된 것이 아님**.
4. 누락된 IEX 체결/분봉은 UNKNOWN 처리하고 A/B 점수 발급, 자동매수, 운영 이전 금지.
5. 다음으로 관측 결과가 실제로 나타나면 대조군(실패/무신호) 포함한 표본 누적과 스프레드/실제 체결 검증.

**절대 변경 금지:** 운영 `main`, API/radar, 기존 스캐너 예약, 고정 5거래일/20거래일 시험, 기존 Stage24 고정 신호.
**상태:** NOT_VALIDATED · NO_ORDERS.
