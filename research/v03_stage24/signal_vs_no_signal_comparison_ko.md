# V0.3 — 신호 종목과 무신호 종목의 공정 비교 설계 (오프라인)

## 목적
급등 신호가 나온 종목만 골라 성과를 계산하면 결과가 좋아 보일 수 있습니다. 같은 시각에 관찰한 **신호 없는 종목**도 포함해야 합니다. 이것을 대조군이라고 부릅니다.

## 반드시 지킬 규칙
1. **같은 후보 명단:** T0(관찰 시작 시각)에 확정한 후보를 그대로 사용합니다. 나중에 오른 종목만 추가하지 않습니다.
2. **같은 시각:** 신호 종목은 신호가 확인된 1분봉 종료 시각을 기준으로 삼습니다. 무신호 종목은 사전에 정한 동일한 관찰 시각을 사용합니다. 신호를 뒤늦게 알았던 시점으로 소급하지 않습니다.
3. **같은 가격 출처:** IEX 단일 거래소 자료끼리만 비교합니다. IEX는 전체 미국 시장 가격이 아니며, 자료가 없는 구간은 '확인 불가'입니다.
4. **같은 관찰 길이:** 5/15/30/60분 결과를 각각 별도로 비교하고, 양쪽에 자료가 있는 표본 수를 함께 공개합니다. 현재 35분 원본만으로 60분 성과를 계산하지 않습니다.
5. **실패 포함:** 하락, 무신호, 거래정지, 유동성 부족, 스프레드(매수·매도 호가 차이) 및 거래 불가 사례를 숨기지 않습니다.
6. **미래정보 금지:** 신호 판단에는 신호 당시까지 알 수 있었던 가격·뉴스·공시만 사용합니다.
7. **수익률과 실제 수익 구분:** 봉 종가끼리 비교한 변화율은 체결 수익이 아닙니다. 실제 매수·매도 가능 가격, 수수료, 슬리피지(원하는 가격과 실제 체결가 차이)를 반영하기 전에는 투자 수익으로 부르지 않습니다.
8. **사전 기준 고정:** 성공 기준(예: 이후 +5% 도달), 관찰 기간, 누락 처리, 종목 제외 조건을 결과를 보기 전에 문서로 고정합니다. +5%는 예시이며 검증된 기준이 아닙니다.

## 현재 자료에서 할 수 있는 것
- 원본 IEX 봉과 신호 계산 입력 6개가 일치하는지 확인
- 신호별 실제 관찰 가능한 5/15/30분 봉 종가 변화 계산
- 자료가 부족한 60분 및 결측 결과는 확인 불가로 기록
- 신호가 없었던 종목의 수와 관찰 누락 수를 세어 기록

## 아직 할 수 없는 것
- 무신호 종목의 비교 기준 시각을 정하지 않고 성과를 직접 비교하기
- 35분 자료로 60분 성과를 추정하기
- 합성 자료 시험 결과를 실제 예측 성공률이라고 주장하기
- SEC 희석 위험 미검증 상태에서 실전 매수 등급 부여하기

**연구 상태: NOT_VALIDATED / SEC_UNVERIFIED / D / NO_ORDERS.**
**3차 실측·시장 API 호출·승인 Secret·실제 주문은 이 문서 작업에 포함되지 않습니다.**
