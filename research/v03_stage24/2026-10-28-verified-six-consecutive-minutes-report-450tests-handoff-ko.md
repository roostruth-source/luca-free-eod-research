# 루카 V0.3 — 2차 실제 실측 '6분 연속 기록' 검사 가능 여부 자동 보고 (2026-10-28)

## 이번 개선 내용
첫 실제 실측에서 12종목 중 5종목은 14분 동안 IEX 1분봉을 6개조차 확보하지 못해, 6개 연속 분봉 패턴을 구조적으로 검사할 수 없었음. 다른 6종목은 6개 이상 분봉을 확보했지만 당시 개별 타임스탬프(자료가 찍힌 시각) 보존이 없어 연속성 확정 불가. JBLU만 14분 모두 확보. 신호 0개는 급등 부재 증거가 아님.

2차 실제 실측 자료를 검증한 뒤, 후속 관찰에서 만드는 한국어 보고서에 아래를 표시하도록 **연구 결과 표시 부분만** 고침.
- 후보별 **가장 긴 연속 관찰 길이(분)**.
- 1분봉이 **6개 연속 존재하는 구간** 수(한 구간 안에서 겹치는 6분 창 모두 계산).
- 후보별 구분: (1) 6연속 분봉 자체가 없어 **전조 검사 불가**, (2) 6연속 분봉이 있고 **연구 패턴 관측 안 됨**, (3) **연구 패턴 기록**. (2)는 급등 실패나 수익률 0%를 의미하지 않음.
- 전체 후보 중 전조 검사가 가능/불가능했던 종목 수. 수집률 숫자만으로 충분한지 오판하지 않도록 개선.

새 순수 계산 모듈: `research/v03_stage24/second_six_minute_evaluability.py`. 실제 출처 검증 `compare(load_verified(),...)` 통과 후에만 분 단위 시각 배열을 분석하며, 누락된 분을 채우거나 가격/거래량 값을 만들지 않음.

기존 `second_korean_research_report.py`가 위 검증 결과를 자동 반영하도록 수정. **실측 원본 수집 코드, 패턴 탐지 조건, 장중 예약, 매매/알림/운영판은 변경하지 않음**. 기존 예약된 2차 후속 워크플로가 정상 성공하면 새 형태의 한국어 보고서가 생성될 예정. 실제 장중 실행 성공까지 이번 코드 시험으로 주장하지 않음.

## 검증한 구체적 예시 (모두 가상 자료)
- 1분봉 **6개가 있어도 서로 떨어져 있으면 6분 연속 창 0개 → 검사 불가**.
- 분봉 6개가 연속 있으면 → 검사 가능 1개. 패턴이 안 나오면 해당 조건에 맞지 않은 것뿐, 향후 급등 안 한다는 뜻 아님.
- 15분 내내 자료가 있으면 6분 연속 창 **10개**(겹치는 창 포함).
- 기록 0개면 검사 불가. 자료 조작 또는 패턴이 없던 구간에 가짜 신호를 붙이면 중단.
- 실제 후속 보고서의 한국어 문장도 위 구분을 정확히 유지하는지 테스트.
